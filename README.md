# Daymark Habit Tracker

Daymark is a habit tracker built with HTML, CSS, and JavaScript. You can create habits, divide them into checkpoints, and mark them complete each day.

## Features

- Add, edit, and delete habits.
- Add up to five checkpoints to each habit.
- See daily progress, streaks, and a seven-day chart.
- Look back at previous days.
- Choose from four color themes.
- Save habits in the browser with localStorage.

## Files

- index.html: page content and the habit form
- style.css: layout and component styles
- themes.css: colors for each theme
- script.js: habit data, dates, and interactions

## Run the project

Open index.html in a browser. No installation is needed.

Your data is saved in your browser, so it will not automatically appear on another device. Clearing browser data will also remove your saved habits.

## Deployment

This is a static website. It can be hosted with GitHub Pages by publishing the repository's main branch from the root folder.
